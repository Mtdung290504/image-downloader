Image Downloader

⚠ Why does browser show a warning bar?
This extension uses the Chrome Debugger API to download images from protected sites, so browser shows a warning bar at the top of the page.

⚠ Keep this bar visible while downloading images — closing it may cause downloads to fail.

If you don't want to see this warning anymore, simply disable the extension when you're not using it.
